Supervisor Layout Axioms

1. Zero Border Philosophy

Components communicate hierarchy through background contrast steps (surface → surface-container-low → surface-container) rather than sharp hard border lines.

2. High Tactile Minimums

Gloved hands and wet touchscreen scenarios require minimum 48px heights on high-frequency triage actions like Pen Transfers and Vet Holds.

3. Strict Content Containment

Max-width is constrained at 1600px desktop to prevent excessive eye-tracking strain while pacing parlor catwalks.
